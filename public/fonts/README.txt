Melloida font slot
==================
This folder is checked first for the display font:

  MelloidaDemo.ttf   (or MelloidaDemo.otf)

The site already references it via @font-face in app/globals.css.
Until the file exists here, headings fall back to Bodoni Moda (Google Fonts).

Where to get the demo (free for personal use):
  https://www.1001fonts.com/melloida-demo-font.html
  https://befonts.com/melloida-font.html

Download the zip, extract the .ttf, and place it in this folder —
no rebuild needed, refresh the page and Melloida takes over.
(Commercial use requires a license from Din Studio / Fontspring.)
